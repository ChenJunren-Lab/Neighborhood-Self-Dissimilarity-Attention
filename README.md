# Neighborhood Self-Dissimilarity Attention for Medical Image Segmentation

## Methodology
![Overview of NSDA](./assets/NSDA.png "")
Overview of our parameter-free Neighborhood Self-Dissimilarity Attention (NSDA).  (a) illustrates the NSDA architecture for every element, which uses our proposed Gaussian-kernel-based method to measure element-neighborhood dissimilarity, giving higher weights to elements with more salient differences.  (b) depicts the dissimilarity-driven weighting curve generated by NSDA, while (c) shows the conventional sigmoid-based weighting curve employed in traditional attention mechanisms.  Compared to traditional sigmoid-based methods, NSDA eliminates sign-induced bias, thereby ensuring equitably weighted contributions from features with opposing polarity.

## Usage of NSDA
See `NSDA.py` for specific usage.

```python
import NSDA

input      = torch.randn(8, 16, 64, 64)
b, c, h, w = input.shape
attention  = NSDA(in_channels=c, out_channels=c)
output     = attention(input)
```
