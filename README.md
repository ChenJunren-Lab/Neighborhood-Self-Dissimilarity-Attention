# Neighborhood Self-Dissimilarity Attention for Medical Image Segmentation

## Methodology
![Overview of NSDA](./assets/NSDA.png "Overview of our proposed Neighborhood Self-Dissimilarity Attention (NSDA). (a) illustrates the NSDA architecture for every element, which uses our proposed Gaussian-kernel-based method to measure element-neighborhood dissimilarity, giving higher weights to elements with more salient differences. (b) depicts the dissimilarity-driven weighting curve generated by NSDA, while (c) shows the conventional sigmoid-based weighting curve employed in traditional attention mechanisms.    Compared to traditional sigmoid-based methods, NSDA eliminates sign-induced bias, thereby ensuring equitably weighted contributions from features with opposing polarity.")

## Usage of NSDA
```python
input      = torch.randn(2, 3, 8, 8)
b, c, h, w = input.shape
attention  = NSDA(in_channels=c, out_channels=c)
output     = attention(input)
```

See `NSDA.py` for specific usage.

## NSDA-augmented Network
We integrate NSDA on four established neural networks for medical image segmentation:
- U-Net: The code is available at `NSDA-augmented-UNet.py`.
- TransUNet: The code is available at `NSDA-augmented-TransUNett.py`. It script requires the following Python files as dependencies: 
    - vit_seg_configs.py
    - vit_seg_modeling.py       
    - vit_seg_modeling_resnet_skip.py  
- UNeXt: The code is available at `NSDA-augmented-UNeXt.py`.
- TinyU-Net: The code is available at `NSDA-augmented-TinyUNet.py`.
